## 2. Objection kit (for DMs / live Q&A)

| Objection | Honest response |
|---|---|
| "No time" | ~20 min/day; consistency > intensity; community keeps you on track. |
| "I've tried before" | You had tips, not a **system + accountability**. Step-by-step build + coaching = you finish. |
| "Too expensive" | Tiered + installments + challenge credit; compare to years of failed self-study/tutors. We sell a **result**. |
| "Is the accent guaranteed native?" | No — clear, confident, American-leaning; native-like is a ceiling for the most dedicated. Honest. |
| "I'm too weak / from zero" | Exactly who it's built for — starts from zero, Arabic-scaffolded early. |
| "Not sure it works" | Do the **7-day challenge** first (low cost, credited) and see your own before/after. |

## 3. Live Q&A / info-session outline (~40 min)

1. **Welcome** (2 min) — who this is for.
2. **Founder story** (3 min) — the relatable→aspirational journey.
3. **Why most people fail** (5 min) — tips vs system; the dropout problem.
4. **The EEC system + roadmap** (8 min) — input+speaking+review, Accent Lab, mindset; zero → B2.
5. **What's included + the guarantee** (5 min).
6. **Pricing + founding offer + deadline** (5 min).
7. **Live Q&A** (10 min) — use the objection kit.
8. **Soft close** (2 min) — spots + deadline + link; "any question, DM me."

## 4. Enrollment pipeline

Track every lead through stages (companion CSV: `operations/enrollment-pipeline-template.csv`):
```
Lead → Challenge signup → Challenge completed → Cohort invited → Interested → Paid → Onboarded → Ready for Day 1
```
Columns: name · contact · tier · source · stage · last_touch_date · notes. Daily: advance stages;
follow up "Interested but not Paid." Feed **Paid+** into the Cohort Tracker (Task 0.5).
