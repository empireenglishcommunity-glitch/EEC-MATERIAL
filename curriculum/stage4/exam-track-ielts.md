## 0. About the test (orientation)

- **IELTS** = International English Language Testing System (UK/Commonwealth-oriented; universities, migration, work).
- **Two versions:** **Academic** (university) and **General Training** (migration/work) — Listening + Speaking are
  the same; **Reading + Writing differ**.
- **Four sections:** **Listening · Reading · Writing · Speaking** (~2h45; Speaking is a live 11–14 min interview, may be a separate day).
- **Scoring:** each section **band 0–9** → overall **band 0–9** (averaged, rounded to nearest half-band). Common targets: 6.5–7.5.
- **Key traits:** variety of accents (British/Australian/etc.); handwritten or computer-delivered; **Writing Task 1**
  differs by version (Academic = describe a graph/chart/process; General = a letter); **Task 2** = an essay (both versions);
  **Speaking** = a friendly 3-part interview.

> These are stable format facts; **confirm the current official format/timing on the official IELTS site
> (IDP/British Council/Cambridge) before a test date**, and choose **Academic vs General** per the candidate's goal.

## 1. Module goals & structure

- **Goal:** the candidate can navigate the IELTS format (correct version) confidently, apply per-section
  strategies, manage time, handle varied accents, and produce band-target Writing + Speaking — reaching their target band.
- **Approach (shared with TOEFL module):** **diagnostic → format familiarization → per-section strategy →
  timed skill drills → full timed mock(s) → band-scored feedback → targeted improvement loop.**
- **Sessions (≈ lessons):**
  - E-I01 Orientation + version choice + diagnostic → baseline band + plan
  - E-I02 Listening — accents + question types + timed practice
  - E-I03 Reading — (Academic/General) strategies + timed practice
  - E-I04 Writing Task 1 — (Academic: data/process · General: letter)
  - E-I05 Writing Task 2 — the essay (both versions)
  - E-I06 Speaking — the 3-part interview (Parts 1–3)
  - E-I07 Full timed mock + band feedback → targeted improvement + readiness

## E-I01 — Orientation + Version Choice + Diagnostic

**Metadata:** Stage 4 / Exam Track · ~90 min · prerequisites: strong B2/C1.
**Objectives:** choose **Academic vs General Training** (by goal); understand the format + band scoring; take a
short diagnostic; get a baseline band estimate + plan and target.
**Flow:** version decision (university → Academic; migration/most work → General) → format/band walkthrough →
short diagnostic (a listening set, a reading set, a Task 2 paragraph, 2–3 speaking questions) → estimate bands vs descriptors → set target + plan.
**Assets:** format one-pager (both versions); a mini diagnostic; a band-tracking sheet.
**Coach notes:** choosing the right version is step one — Reading/Writing differ; don't prep the wrong one.

---

## E-I02 — Listening (Accents + Question Types + Timed Practice)

**Metadata:** ~75 min. **Objectives:** handle multiple accents; answer the range of question types accurately under time.
**Content:** 4 recorded sections (everyday + academic); question types: multiple choice, matching, plan/map/diagram labeling, form/note/table completion, sentence completion.
**Strategy:** predict answers from questions; listen for paraphrase (answers rarely use the exact words); watch word limits (e.g., "no more than two words"); transfer answers carefully; reuse C1 Unit 6 accent + note skills.
**Flow:** question-type tactics → guided section → timed set → review paraphrase traps → log accuracy by type.
**Assets:** question-type card; multi-accent clips; an error log.
**Coach notes:** paraphrase recognition + word limits cause most avoidable losses — drill both.

---

## E-I03 — Reading (Academic / General — Strategies + Timed Practice)

**Metadata:** ~75 min. **Objectives:** apply reading strategies for the chosen version under strict time.
**Content:** Academic = 3 long academic-style texts; General = everyday/workplace texts + a longer passage. Shared
question types: T/F/Not Given, Yes/No/Not Given, matching headings/info, completion, multiple choice.
**Strategy:** skim for structure; scan for keywords/paraphrase; master **T/F/Not Given vs Yes/No/Not Given** (the classic trap); manage ~20 min/passage; don't get stuck.
**Flow:** type-by-type tactics (esp. Not Given) → guided passage → timed passage → review → accuracy by type.
**Assets:** a question-type card (Not-Given focus); timed passages (version-appropriate); an error log.
**Coach notes:** "Not Given" is the top confusion — teach it explicitly (no evidence either way ≠ False).

---

## E-I04 — Writing Task 1 (Academic: Data/Process · General: Letter)

**Metadata:** ~75 min. **Objectives:** produce a band-target Task 1 in ~20 min for the correct version.
**Academic Task 1:** describe/summarize a graph/chart/table/process/map — overview + key features + accurate data language, **no opinion**.
**General Task 1:** write a letter (formal/semi-formal/informal) — correct tone, cover all bullet points, appropriate conventions.
**Strategy:** structure (intro → overview → details); data/trend language (Academic) or letter conventions + register (General; reuse C1 Unit 4); hit ~150 words; time-box to ~20 min.
**Flow:** version-appropriate structure + model → guided outline → timed write → score vs band descriptors → revise.
**Assets:** structure templates (both versions); data-language / letter-convention cards; model answers.
**Coach notes:** Academic Task 1 needs an accurate **overview** (a band lever); General letters need correct **tone** — reuse register control from C1.

---

## E-I05 — Writing Task 2 (The Essay — Both Versions)

**Metadata:** ~75 min. **Objectives:** produce a band-target ~250-word essay in ~40 min answering the exact question.
**Question types:** opinion (agree/disagree), discussion (both views + opinion), problem/solution, advantages/disadvantages, two-part.
**Strategy:** answer the **exact** question; clear position; 4-paragraph structure (intro → 2 body → conclusion); topic sentences + support + example; cohesion (reuse C1 Unit 1); appropriate register + hedging (reuse C1 Unit 4/8); ~250 words; time-box ~40 min.
**Flow:** question-type analysis + models → guided outline → timed essay → score vs the 4 band criteria (task response, cohesion, lexical resource, grammar) → revise.
**Assets:** question-type + structure cards; model essays; the 4-criteria band descriptors.
**Coach notes:** the #1 band killer is not answering the exact question — drill question analysis first. Reuse C1 argument + cohesion + register.

---

## E-I06 — Speaking (The 3-Part Interview)

**Metadata:** ~75 min. **Objectives:** handle the live 11–14 min interview across all three parts confidently.
**Parts:** **Part 1** familiar-topic Q&A (~4–5 min); **Part 2** the "long turn" — a 1–2 min talk from a cue card (1 min prep); **Part 3** an abstract discussion linked to Part 2 (~4–5 min).
**Strategy:** Part 1 = natural, extended answers (not one-word); Part 2 = use the cue-card prompts + prep notes, structure the talk, keep going for the full time (reuse C1 Unit 7 fluency); Part 3 = opinions + reasons + nuance (reuse C1 Units 8/9); fluency + range + pronunciation + coherence are the four band criteria.
**Accent Lab focus:** natural fluency, pronunciation, and prosody in a live interview (reuse C1 prosody + spontaneity).
**Flow:** part-by-part strategy + models → guided practice → timed mock interview (record) → score vs the 4 criteria → refine (esp. Part 2 long turn).
**Assets:** cue cards; part-by-part strategy card; the speaking band descriptors; recording setup.
**Coach notes:** Part 2 (the long turn) is where many candidates stall — drill sustaining 1–2 min from a cue card (reuse C1 spontaneity/extended discourse).

---

## E-I07 — Full Timed Mock + Targeted Improvement (Final Readiness)

**Metadata:** ~2h45 (full test) + review + focused drills. **Objectives:** complete a full, timed mock; get band-scored feedback; close gaps; confirm readiness vs target.
**Flow:** full timed mock (Listening + Reading + Writing + Speaking) under realistic conditions → band-score each section vs descriptors → debrief → focused drills on the weakest section(s) → (optional) a second Writing/Speaking mock → final readiness call + test-day plan (logistics, timing, nerves).
**Assets:** a full mock set (version-appropriate); per-section band-scoring sheets; a test-day checklist.
**Coach notes:** confirm the candidate consistently hits (or is close to) the target band before booking; give an honest readiness assessment (not a guarantee).

---

## Assessment & reporting

- **Diagnostic + full mock(s)** with **section bands (0–9) + overall band** vs the candidate's target.
- Track accuracy by question type (Listening/Reading) + the 4 criteria each for Writing/Speaking across attempts.
- Feed results to the Cohort Tracker; produce a final **readiness report** (honest go/not-yet-ready + gaps).
